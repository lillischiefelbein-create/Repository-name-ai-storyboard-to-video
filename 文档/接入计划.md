# 外部接口接入计划

## 一、准备事项

- 飞书开发者应用及三张多维表格的有效授权；需要读取、写入记录、上传图片附件。
- 图片模型接口：支持图像生成和基于已存在图片的精修；密钥仅存在私有运行环境。
- 用户授权或公开合法的参考素材来源；尽量保留具体笔记链接和出处。
- 常驻事件处理器或定时服务：订阅飞书更新、轮询新反馈，并在截止时间归纳；Codex Skill 本身不全天运行。

## 二、先验证三张表

1. 创建“视觉质量标准库”。
2. 创建“总资产表”，主视图真实展示当前图片并提供详情卡。
3. 创建“分集顺场表”，按编号同步当前图片，验证图片字段是真实附件而非只有链接文字。
4. 测试版本变化后，主表/顺场表能同步看到最新图片。
5. 详情卡中的历史下拉若原生组件不支持，应使用可验收的详情视图或扩展，不应假装已经实现。

## 三、按钮与状态

参考通过/否决 → 全部必要参考通过 → 明确允许生成 → 图片生成 → 待审核 → 需要修改 → 限时反馈 → 截止归纳 → 图片精修 → 新版本 → 无需修改 → 确认终稿。

否决记录原因并重新检索；新增参考再次审核；生成成功以后才发布新版本；终稿明确锁定。所有写入须处理重复通知和状态冲突。

## 四、图片编辑

初版按标准生成；后续以原图加批准的新增参考为输入进行垫图编辑，局部修改优先使用蒙版，保留原版归档。编辑接口不保证未修改区域像素级不变，所以仍要验图和审批。

## 五、执行次序

飞书建表与附件 → 参考审批与当前元素 → 资产关联与顺场同步 → 视频抽帧与检索 → 图像生成精修 → 按截止时间自动归纳与重试。

**当前 0.1.0 只有离线执行逻辑，尚不能自动连接真实飞书或模型。**
