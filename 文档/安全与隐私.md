# 安全与素材边界

1. 不将真实 API 密钥、飞书应用密钥、账号密码、Cookie、个人会话、私有剧本和未授权图片提交到公开仓库。
2. 在合法授权范围内查阅参考；账号授权不代表可以绕过网站登录、验证码、反爬措施和访问限制。
3. 优先保存具体公开笔记的真实来源链接、元素摘要及获准存储的参考副本，不捏造检索结果。
4. 用户上传素材也应确认可使用；避免未经同意复刻可识别的真实人物肖像。
5. 参考、生成、修改和终稿必须通过飞书明确的按钮/字段完成审批，聊天意见不代替审批。
6. 图片模型调用可能产生费用，必须设置预算、幂等校验及失败处理。
7. 仅在本机或密钥管理器中填写 .env；公开的 .env.example 所有值保持空白。
