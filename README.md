# 影视前期视觉资产管理 Skill

**版本：0.1.0｜中文开源初版｜适用于 Codex**

本项目用于 AI 真人短剧和影视前期的视觉资产制作与管理：从对标成品视频提炼质量标准，解析新剧本，制作人物、场景、道具资产，并通过飞书审核参考、收集反馈、控制图片生成和精修版本。

> 当前阶段提供技能规则、三表设计、离线审批与版本处理逻辑、中文示例和测试。**尚未接入实际飞书、外站检索、对标视频抽帧或图片模型，也未部署常驻监听服务。**

## 飞书三张核心表

1. **视觉质量标准库**：对标视频、参考图片、画面规格、审美要求、禁止项和来源。
2. **总资产表**：按人物→场景→道具→关系/特殊分组，组内按 S>A>B>C 排序；主视图直接展示当前资产图。每个资产有详情卡，集中管理参考图片、审批、当前采用元素、反馈及历史下拉。
3. **分集顺场表**：按集与场对应资产，自动展示总资产表的当前图片；新版本发布时更新，不要求用户手动选图。

## 分工与审批

- **用户**：提供新剧本、对标素材和必要授权；必要时上传参考图片；在飞书点击“通过/否决”“允许生成”“需要修改/无需修改”“确认终稿”，参与审阅和反馈。
- **Codex Skill**：统筹拆解、标准提炼、检索任务、已批准元素处理、提示词、流程校验、历史版本、执行接口及质量检查。
- **飞书接口**：展示图片与审批状态、读写附件和表格、多人反馈。
- **图片模型接口**：初版生成，使用上一版图片进行垫图或局部编辑。
- **定时任务或事件处理服务**：持续接收反馈并在截止时间后触发汇总。**仅有 Skill 文件不会无人值守持续运行。**

每份候选参考需要真实图片、合法可访问的具体链接或授权附件，用户单独点击“通过”才可被采用。全部必要部位通过后还需明确点击“允许生成”。自然语言反馈不等于审批。生成后可反复修改；上一版元素继承，按保留、替换、强化、新增、删除记录；**只有点击“确认终稿”才能终稿锁定**。

## 图片规范

- 人物：横版 16:9 单张综合图；左侧面部大特写＋右侧正/侧/背三视图；白底、平光、面貌与服装一致、真人质感。
- 场景：16:9 全景，结构完整、纵深清楚、亮度适当、真人影视感。
- 道具：结构、材质、纹理和用途明确。
- 修改：优先使用上一版图片和通过审批的参考垫图修改；局部修改使用图像编辑能力，仍要检查未指定区域是否变化。

## 安装到 Codex

将本仓库下载到本机，在 Codex 技能目录放置整个项目文件夹，并确保其中存在 SKILL.md。示例：

    mkdir -p ~/.codex/skills
    cp -R Repository-name-ai-storyboard-to-video ~/.codex/skills/影视前期视觉资产管理Skill

打开 Codex 后要求使用“影视前期视觉资产管理”技能。当前只可用离线数据验证流程，不会在缺少授权时自动操作真实平台。

## 本地测试

在仓库目录执行：

    python -m unittest discover -s 测试 -v

无需互联网、API 密钥或第三方依赖。

## 配置与安全

参见 .env.example。所有密钥、账号、访问地址均为空；将本地设置放在不提交的 .env 中。不要提交剧本、未授权视频、Cookie、登录会话、飞书凭据或真实图片。开源许可证全文在 LICENSE 内。
