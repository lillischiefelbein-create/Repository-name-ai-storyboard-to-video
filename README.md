# 影视前期视觉资产管理 Skill

**版本：0.1.0｜中文开源初版｜适用于 Codex**

本项目用于 AI 真人短剧和影视前期的视觉资产制作与管理：从对标成品视频提炼质量标准，解析新剧本，制作人物、场景、道具资产，并通过飞书审核参考、收集反馈、控制图片生成和精修版本。

> 当前阶段提供技能规则、三表设计、离线审批与版本处理逻辑、中文示例和测试。**尚未接入实际飞书、外站检索、对标视频抽帧或图片模型，也未部署常驻监听服务。**

## 飞书三张核心表

1. **视觉质量标准库**：对标视频、参考图片、画面规格、审美要求、禁止项和来源。
2. **总资产表**：按人物→场景→道具→关系/特殊分组，组内按 S>A>B>C 排序；主视图直接展示当前资产图。每个资产有详情卡，集中管理参考图片、审批、当前采用元素、反馈及历史下拉。
3. **分集顺场表**：按集与场对应资产，自动展示总资产表的当前图片；新版本发布时更新，不要求用户手动选图。

## 分工与审批

- **用户**：提供新剧本、对标素材和必要授权；必要时上传参考图片；在飞书点击“通过/否决”“允许生成”“需要修改/无需修改”“确认终稿”，参与审阅和反馈。
- **Codex Skill**：统筹拆解、标准提炼、检索任务、已批准元素处理、提示词、流程校验、历史版本、执行接口及质量检查。
- **飞书接口**：展示图片与审批状态、读写附件和表格、多人反馈。
- **图片模型接口**：初版生成，使用上一版图片进行垫图或局部编辑。
- **定时任务或事件处理服务**：持续接收反馈并在截止时间后触发汇总。**仅有 Skill 文件不会无人值守持续运行。**

每份候选参考需要真实图片、合法可访问的具体链接或授权附件，用户单独点击“通过”才可被采用。全部必要部位通过后还需明确点击“允许生成”。自然语言反馈不等于审批。生成后可反复修改；上一版元素继承，按保留、替换、强化、新增、删除记录；**只有点击“确认终稿”才能终稿锁定**。

## 图片规范

- 人物：横版 16:9 单张综合图；左侧面部大特写＋右侧正/侧/背三视图；白底、平光、面貌与服装一致、真人质感。
- 场景：16:9 全景，结构完整、纵深清楚、亮度适当、真人影视感。
- 道具：结构、材质、纹理和用途明确。
- 修改：优先使用上一版图片和通过审批的参考垫图修改；局部修改使用图像编辑能力，仍要检查未指定区域是否变化。

## 安装到 Codex

### 方法一：让 Codex 自动安装（推荐）

在 Codex 对话框中输入：

```text
$skill-installer 请从这个公开 GitHub 仓库安装技能：
https://github.com/lillischiefelbein-create/Repository-name-ai-storyboard-to-video

技能入口在仓库根目录 SKILL.md。
请安装到我的个人技能目录，完成后检查是否可以使用。
```

Codex 内置的技能安装器支持从其他公开 GitHub 仓库安装技能。安装失败时，可改用下面的手动方法。

### 方法二：使用终端手动安装

在 macOS、Linux 或可使用 Bash 的环境中运行：

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/lillischiefelbein-create/Repository-name-ai-storyboard-to-video.git ~/.agents/skills/visual-asset-management
```

安装后的目录必须包含 `~/.agents/skills/visual-asset-management/SKILL.md`。

Windows PowerShell 示例：

```powershell
New-Item -ItemType Directory -Force "$HOME\.agents\skills" | Out-Null
git clone https://github.com/lillischiefelbein-create/Repository-name-ai-storyboard-to-video.git "$HOME\.agents\skills\visual-asset-management"
```

在 Codex 内输入 `/skills` 查看已安装技能，或在提问中输入 `$visual-asset-management` 明确启用。如果未显示，请重启 Codex。

如果只希望在一个工程中使用，可将文件夹复制到该工程的 `.agents/skills/visual-asset-management`。

### 注意

**安装成功不等于已经实现飞书实时同步和自动出图。** 0.1.0 是可供 Codex 阅读、运行离线流程和后续扩展的基础技能。完整运行前需要使用者自行合法申请飞书应用权限、图片模型 API、参考素材访问授权和后台任务调度，不共享作者的 API 密钥。

## 本地测试

在仓库目录执行：

    python -m unittest discover -s 测试 -v

无需互联网、API 密钥或第三方依赖。

## 配置与安全

参见 .env.example。所有密钥、账号、访问地址均为空；将本地设置放在不提交的 .env 中。不要提交剧本、未授权视频、Cookie、登录会话、飞书凭据或真实图片。开源许可证全文在 LICENSE 内。
