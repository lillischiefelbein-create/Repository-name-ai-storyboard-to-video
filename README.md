# 影视前期视觉资产管理 Skill

**版本：0.1.0｜中文开源初版｜可安装到 Codex**

本项目用于真人短剧和影视前期视觉资产制作：对标视频分析、视觉质量标准制定、人物场景道具管理、飞书参考素材审核、用户反馈与多轮图片精修。

飞书核心结构：视觉质量标准库、总资产表、分集顺场表。

用户在飞书审阅、上传必要素材、点击参考通过或否决、批准生成、提出修改和确认终稿。Codex 负责自动编排；图片生成需接入独立图像模型接口。

**当前状态：初版仅提供技能规则、三表字段模板和离线流程代码，尚未实际接入飞书、平台检索和图像生成接口。**

账号和 API 配置信息均为空白，公开仓库不存放真实剧本、账号、Cookie 或未授权图片。
